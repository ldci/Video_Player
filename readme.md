#Red language and FFmpeg

This repository regroups a series of tests for interfacing Red language and ffmpeg or mpv frameworks.

###Code was developed for the new Red ARM-64 version under macOS 27.0.1 (Golden Gate) and is 64-bit.

Old 32-bit version can be founded here: [https://github.com/ldci/ffmpeg](https://github.com/ldci/ffmpeg)

##You need:

Red language: [http://www.red-lang.org](http://www.red-lang.org)

###For macOS ARM-64: [https://github.com/qtxie/red/releases](https://github.com/qtxie/red/releases)

###FFmpeg (including *ffplay* and *ffprobe*): [https://www.ffmpeg.org/](https://www.ffmpeg.org/) 

###mpv [https://mpv.io](https://mpv.io) and socat. For socat, use Hombrew for install or update. 

##You'll find:
1. Tools for  video capture from computer's camera and microphone.
1. Tools for playing video movies. 

See [https://redlcv.blogspot.com/2019/08/redcv-and-ffmpeg-video-and-audio-capture.html](https://redlcv.blogspot.com/2019/08/redcv-and-ffmpeg-video-and-audio-capture.html) for more details.
